# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

Both OpenCart lines are released from this repository and share one version
number, so an entry applies to 3.x and 4.x alike unless it says otherwise.

Write the entry in the same commit that bumps `'version'` in
`system/config/worldline.php`. Merging to `master_3` or `master_4` tags that
version and publishes a release, and the release notes are filled in by hand from
what is written here.
